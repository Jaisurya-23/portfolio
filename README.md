# Personal Portfolio

A modern and interactive personal portfolio website designed to present my professional experience, projects, and work in a clean and engaging way.

The portfolio is built entirely with **HTML, CSS, and JavaScript**, with a focus on responsive design, smooth interactions, and a developer-oriented user experience.

## Features

* Fully responsive design for desktop and mobile
* Dark and light theme support
* Interactive command-line terminal
* Animated particle background using Canvas
* Smooth scroll and reveal animations
* Interactive project cards and navigation
* Resume download and contact options
* Clean, modern developer-focused UI

## Built With

`HTML` · `CSS` · `JavaScript` · `Canvas API`

No frameworks or external JavaScript libraries are required.

## Run Locally

Clone the repository:

```bash id="mpc7as"
git clone <repository-url>
```

Open `index.html` directly in your browser or run it using a local development server such as **Live Server**.

## Deployment

The portfolio is a static website and can be deployed easily on any static hosting platform.
